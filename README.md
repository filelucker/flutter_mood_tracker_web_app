# Flutter Mood Tracker Web Application

A simple mood tracker built with Flutter Web featuring custom-drawn expressions using `CustomPainter`.

## Features
- **Mood Logging**: Log your current mood (Happy, Neutral, Sad).
- **Custom Graphics**: Faces are drawn directly on the Canvas using `CustomPainter` (no images or fonts).
- **Interactive Timeline**: View the past 7 mood entries in a scrollable horizontal list.
- **Animations**: Tap on past entries to see a scale animation.

## Tech Stack
- Flutter (Web)
- CustomPainter for graphics
- AnimationController for interactive feedback

## Deployment
This app is ready to be deployed to Vercel or any other web hosting provider.
